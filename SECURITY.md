# Security policy

## Supported versions

Security fixes are applied to the latest released minor version while Effectprint is pre-1.0.

## Report a vulnerability

Please use GitHub private vulnerability reporting on the Effectprint repository. If that is unavailable, contact the maintainer through the private contact method listed on the maintainer's GitHub profile.

Do not open a public issue for a safe-mode bypass, remote-target authorization flaw, report injection, or vulnerability that could cause persistent side effects.

Include:

- Effectprint, Node, browser, and operating-system versions
- A minimal local fixture or private reproduction repository
- The command you ran
- The effect Effectprint should have blocked
- Whether any real external state changed

Please test only systems you own or are authorized to assess. Use fake credentials and disposable data.
